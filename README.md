# GROOMTRACK — Program Edukasi Pencegahan Child Grooming (3R)
Dikembangkan oleh **N2K Team SMP Negeri 5 Yogyakarta**.

## Cara Deploy ke GitHub & Vercel
1. Ekstrak seluruh isi file ZIP ini (`index.html`, `vercel.json`, `README.md`).
2. *(Opsional)* Jika ingin memutar video lokal secara langsung di web, salin file video MP4 ke folder yang sama dan ubah namanya menjadi `video.mp4`. Jika tidak ditambahkan pun, kartu lirik berilustrasi dan tautan langsung YouTube tetap tampil rapi tanpa error.
3. Unggah seluruh file ke repository **GitHub**, lalu hubungkan ke **Vercel** (`Add New -> Project -> Deploy`).
